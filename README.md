# Free Games

A free, cross-platform game collection built with **Flutter** — one codebase that
runs on **Android and iPhone** with the same UI.

The app is a launcher: a home screen lists games, and each opens on its own screen.
It's a hardcore arcade — fast, punishing, one-shot games:

- 🗼 **Stack** — a block slides back and forth; tap to drop it dead-center. Any
  overhang is sliced off and it speeds up fast.
- 🔀 **Flip** — a glowing runner pulled by gravity; tap to flip to the ceiling and
  dodge the bars. One touch = dead.
- ⚠️ **Dodge** — drag your core through an accelerating storm of falling hazards.
  One hit ends the run.

## Running on your phone

### Android (works now, no Mac needed)

Every push to `main` triggers a GitHub Actions build that compiles a debug APK and
publishes it to the **`latest-debug`** release.

1. Go to the repo's **Releases** page → **Latest Debug Build**.
2. Download `app-debug.apk` onto your Android phone.
3. Open it and allow "install from unknown sources" when prompted.

### iPhone (needs setup later)

Apple requires a **Mac with Xcode** to build an iOS app, and an **Apple Developer
account ($99/yr)** + TestFlight to install it on a real iPhone — this is an Apple
rule, not a Flutter limitation. The iOS build is already scaffolded (`ios/` folder)
and the CI has a ready-to-enable iOS job (commented out in
`.github/workflows/build.yml`). When you have a Mac or an Apple account, we flip
that on.

## Project layout

```
lib/
  main.dart                      # app entry + MaterialApp
  theme.dart                     # brand colors + Material 3 theme
  home_screen.dart               # the game launcher menu
  games/
    stack_screen.dart            # block-stacking precision arcade
    flip_screen.dart             # gravity-flip dodge
    dodge_screen.dart            # survive the falling-hazard storm
test/
  widget_test.dart               # smoke tests
android/  ios/                    # native wrappers (generated by Flutter)
.github/workflows/build.yml      # CI: builds the APK and publishes a release
```

## Adding a new game

1. Create `lib/games/<your_game>_screen.dart` with a `StatelessWidget` /
   `StatefulWidget` screen.
2. Add a `_GameEntry` to the list in `lib/home_screen.dart`, setting `builder` to
   open your new screen (leave `builder` out for a "coming soon" card).

## Developing locally

Install Flutter (https://docs.flutter.dev/get-started/install), then:

```bash
flutter pub get
flutter run          # run on a connected device / emulator
flutter test         # run the tests
flutter analyze      # static analysis
flutter build apk --debug   # build an Android APK (needs a JDK + Android SDK)
```
